# Artículo de Riesgo Crediticio

Este repositorio contiene el notebook reproducible utilizado para el artículo:

"Desempeño de Modelos de Machine Learning frente a Regresión Logística en la Estimación del Riesgo Crediticio".

El análisis compara Regresión Logística, Random Forest y XGBoost para la predicción del incumplimiento crediticio usando el conjunto de datos Default of Credit Card Clients.

## Contenido

- Carga y exploración de datos
- Preparación de variables
- Entrenamiento de modelos
- Evaluación mediante accuracy, precision, recall, F1-score y AUC-ROC
- Validación cruzada estratificada
- Matrices de confusión
- Importancia de variables con XGBoost

## Reproducibilidad

El notebook puede ejecutarse en Google Colaboratory. Por defecto, carga el conjunto de datos desde el repositorio público de UCI Machine Learning Repository.
